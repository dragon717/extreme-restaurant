# 峡谷餐厅 · 员工阵容与羁绊策划

**讨论稿。** 以原版两章和现有经营调度为底，新增「选择本局英雄」、特色员工与当班羁绊的设计。文中英雄、野怪与技能是餐厅玩法的改编提案。

## 一天怎样经营

- **夜间规划。** 看次日客流预告和周租，在菜单、排班、灶台、客桌、订单口、出餐口和资金之间做取舍。选中设施、员工站位或试摆时，用沿可走格流动的虚线显示相关路线，例如客桌接单 → 订单口、灶台 → 出餐口、出餐口 → 客桌。预览复用现有寻路规则，让玩家放下之前就能看到绕行、不可达或两条高频通道的交叉。平时隐藏线路。虚线表示当前布局下的典型路径，白天仍按实际订单和可用工位派工。
- **白天营业。** 员工自动接单、烹饪、把菜搬到出餐口、送到客桌并结账。开店前查看当天的应急技能库，白天在突发积压时手动使用少量能力。合理布局足以跑普通客流，技能给玩家一次处置高峰的机会。现有「河道急送」继续手动触发。布兰德白天手按点火是已确认的设计方向。
- **打烊复盘。** 用现有日报比较出餐前等待、出餐后等待、完餐和收入。夜间调整后再对照下一份日报，周租继续决定下一轮用于招人、改造和采购的预算。

原版入口与经营规则见 [游戏设计与开发基准](../游戏设计与开发基准.md)、[README](../README.md) 和 [现行技能与结算调用链](canyon-gameplay.md)。

## 选择本局英雄与两种容量

### 局外收藏、开局五人、章内岗位

| 概念 | 用途 | 起始约定 |
| --- | --- | --- |
| 局外收藏与可调用池 | 通过局外养成扩充已解锁的特色员工 | 新档解锁五位，同时可拥有五位。长期上限、解锁曲线与付费设计待讨论 |
| 选择本局英雄 | 从自己的可调用池确定本局起用的特色员工 | 每次开新局或开章都进入「选择本局英雄」页面，确认五位 |
| 章内岗位容量 | 决定当晚有多少厨师、服务员上岗 | 开局 2 厨师、4 服务员，上限 12 厨师、18 服务员。招聘与扩建增加容量，厨师需要可用灶台 |

[第一章配置](../data/chapter.json)定义起始与上限。[第二章覆盖配置](../data/chapters/market_lane.json)沿用这两项。英雄、野怪、小兵是员工身份。排班只有厨师和服务员两个岗位，同一名员工同一晚占一个岗位。迅捷蟹作为当班野怪时占一个服务员名额。

### 三条选将路径

1. **首次手动选。** 没有保存分组时，从可调用池点选五位，确认本局名单。初期即使池里刚好五位，也通过选将页完成确认。
2. **套用后可编辑。** 从局外保存的分组一键填入五位，随后可替换个别人，再确认本局名单。
3. **手动重选。** 有分组时也可以从头挑选五位，确认新的本局名单。

局外可以新建、保存、修改分组，也可以自定义和修改组名。分组负责快捷填入，本局以正式选将页确认的名单为准。这里的 BP 指开局挑将；当前流程包含选择、套用、替换和确认。

### 六个岗位都有人

开局确认的五位特色员工**可以同时上场**，第六岗由普通小兵补齐。示例用布兰德、潘森、希维尔、迅捷蟹、魔沼蛙演示两种排法。示例假定潘森可选一岗。首发名单、可兼岗角色及能力在不同岗位是否生效仍待定案。

| 排法 | 后厨两个岗位 | 前厅四个岗位 |
| --- | --- | --- |
| 2 特色厨师 + 3 特色服务员 + 1 小兵服务员 | 布兰德、潘森 | 希维尔、迅捷蟹、魔沼蛙、小兵 |
| 1 特色厨师 + 4 特色服务员 + 1 小兵厨师 | 布兰德、小兵 | 潘森、希维尔、迅捷蟹、魔沼蛙 |

小兵按缺岗补后厨或前厅。扩到八个岗位而继续安排五位特色员工时，才由三名小兵补位。

## 技能与积压

### 布兰德 · 烈焰风暴

Riot 在 10.22 增加了火球弹回布兰德本人的逻辑。12.3 调整弹跳顺序，让附近敌人优先于最远距离处的布兰德。餐厅提案保留火球往返的辨识度，以布兰德本人为己方弹跳落点，将目标转成已备锅的合条件灶位。[Riot 10.22](https://www.leagueoflegends.com/en-us/news/game-updates/patch-10-22-notes/) · [Riot 12.3](https://www.leagueoflegends.com/en-gb/news/game-updates/patch-12-3-notes/)

- **夜里配灶。** 把可用灶台布置在布兰德能够串起来的位置，并让帮厨到灶位、成菜到出餐口的路保持通畅。点火范围、邻接和路线上限留待原型实测。
- **白天手按。** 后厨先收到已有订单，帮厨按单备锅。玩家按技能时，火球在布兰德和附近合条件的灶之间跳，点燃最多三口已备好锅的灶。每口灶完成自己的已确认订单，可同时做不同菜。开局有两口合条件灶时点两口，扩到第三口后才可能三口齐开。实际结算使用有效订单与可用灶的交集。
- **继续走原来的服务链。** 帮厨备锅、把成菜搬到出餐口，服务员再取餐送桌。菜品品质、订单和收入沿用原规则。这个技能先救**出餐前的灶台积压**。

现有「三锅旺火」按每名厨师自己的整锅计数，在第三锅自动加速。它与拟议的手动多灶并行各有含义，两者是否同时保留待试玩比较。[现行技能](canyon-gameplay.md)

### 河道急送 · 出餐后的应急

原版已经支持白天手动从出餐口附近开启短时加速。适合菜已经做好、出餐口堆积、服务员来不及取送的情形。表现可尝试希维尔带队、迅捷蟹短时入场和沿路水纹。短时支援沿用现有的加速底座，日常取餐、送餐和结账仍由原调度完成。技能槽、获得方式、次数和冷却的长期方案在首轮试玩后定。[现行河道急送](canyon-gameplay.md)

## 员工羁绊与街区分工

- **当日排班计数。** 第一版羁绊只看当日排班。英雄与野怪有员工身份且上岗时计入，基础小兵主要补岗位。顾客、夜间商人和技能特效在当班名单之外。安妮的提伯斯演出随安妮算一名员工。迅捷蟹作为正式当班员工时计入，短时支援时仍按当班名单判断。客人羁绊留待后续讨论。
- **一人先一项本领。** 优先让白天看得懂能力落在哪段流程。布兰德和安妮可做第一对后厨搭配，晚上安排相邻灶位，安妮协助备好相邻锅，白天由玩家指挥布兰德点火。前厅可比较希维尔与迅捷蟹合作后是否更擅长消化出餐口积压。羁绊阈值、强度以及叠加边界都是待测建议。
- **分区角色。** 上路的奥恩可承接夜间灶台改造，中路布兰德负责后厨，希维尔对应下路前厅，打野艾翁可负责夜间招募野怪。奥恩和艾翁是否同时可雇为章内员工留作选项。
- **兵线与到访。** 上中下路和野区的来客沿用现有分时客流和组桌。近战兵可两人结伴，远程兵零星来店，炮车带三位小兵形成四人桌需求，交给现有事件预告。普通小兵也可以是不同身份的员工补位。可在稀客或团餐事件中安排塔姆探店、派克摸走试吃盘，当日已在岗的同名角色由其他来客替补。

## 后厨候选（12 位）

以下方案各有一项代表本领，菜谱对应只是示例。厨师照样占现有后厨容量。用订单、灶台和成菜状态判断是否触发。

| 员工候选 | 代表本领与服务环节 |
| --- | --- |
| 布兰德 | **烈焰风暴。** 白天手动串起至多三口已备好锅的灶，适合灶前积压。 |
| 潘森 | **烤饼合批。** 同一工位有合条件的同类烤饼订单时，合成一锅烹饪。可作为兼岗讨论候选。 |
| 塔姆 | **慢炖。** 指定慢炖菜在出锅时获得品质优势，适合给高要求客人备餐。作为厨师和探店客分别登记。 |
| 阿卡丽 | **快切冷盘。** 加快单份冷盘制作，让短订单较早出锅。 |
| 蕾欧娜 | **炙烤。** 稳定提高匹配烤肉的成品品质。 |
| 奥拉夫 | **利斧备肉。** 缩短肉菜开火前的备锅时间，先清有肉料的灶前待单。 |
| 莫甘娜 | **照顾久等甜品单。** 从可接的甜品订单里优先挑等得最久的客桌，仍在原订单队列内派工。 |
| 安妮 | **提伯斯帮厨。** 协助准备一口相邻的锅，方便后续串灶。提伯斯随安妮计一个岗位。 |
| 兰博 | **灶台余温。** 同一灶连续使用时，让下一口符合条件的锅提前开火。 |
| 加里奥 | **稳手搬盘。** 合并可同送出餐口的成菜搬运，减少灶台与出餐口的往返。 |
| 努努和威朗普 | **冰品搭档。** 擅长把已有冰品订单做成一锅批次，两位合占一个厨师岗位。 |
| 石甲虫 | **定点大锅。** 固定在适配大锅的工位处理批量订单，位置由夜间布置决定。 |

## 收入、视觉与待测项

普通完餐照现有菜价、品质和客人特性结账。活动额外奖赏可以按已有公告规则评估。0.9 合流后，金币用于采购、奖杯盲盒和经营支出，声望用于招聘和改造等原有成长，闪星用于地块与装饰，周租继续压住资金节奏。

现有实收金额飞向余额和数值滚动继续沿用。高峰付款可合并表现，保留真实逐笔入账。夜市商店可以用翻出的木牌同时交代价格和用途。火球沿真实有效灶位跳，水纹沿实际配送通道出现，角色头顶先显示任务和紧急状态，状态结束就收起。

待试玩确定的包括技能槽、开局技能取得、次数与冷却、羁绊阈值与叠加、长期收藏上限与解锁曲线，以及三锅旺火与手动串灶的并存方式。首轮经济沿用金币、声望、闪星和周租。

## 一次完整试玩

晚上收到炮车四人波预告。玩家把两张双人桌合成四人桌，确认前厅和后厨名单，再试摆出餐口。虚线沿可走格更新，显示出餐口到客桌少绕一个转角。后厨给可用灶留通路，开店前确认当天的应急技能。

白天常规客流靠布局和自动派工完成。四人波到店后，若订单积在灶前，就让已备锅的布兰德手动串灶。若菜已经到出餐口而服务员压单，就手动用一次河道急送。打烊后对照出餐前与出餐后等待、完餐和缴租余量，再决定明晚该挪哪个设施、换谁上岗，或者把哪项技能留到真正需要的时候。

## 云顶之弈参照与当班反馈

员工设计先选一项辨识度高的招式，再确定它影响点单、烹饪还是配送。羁绊通过当日同岗组合或相邻站位增强这项本领。原作的棋子、赛季、技能名和一手链接与餐厅版的触发条件分别记录。岗位图标、演出和数值采用本项目素材与经营规则。

- **连灶飞火。** 云顶《元素崛起》的布兰德用一颗火球弹跳，9.21 的平衡调整明确把弹跳距离作为独立参数。本作让玩家手按，在附近有真实订单的备锅间传火。选将页把炉生的点火列作一项应急技能。[元素崛起棋子说明](https://nexus.leagueoflegends.com/en-gb/2019/10/teamfight-tactics-rise-of-the-elements/) · [云顶 9.21 弹跳距离](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-9-21-notes/)
- **当班羁绊。** 参考《赛博之城》A.M.P. 用羁绊人数强化棋子原有技能，以及街头恶魔通过站位兑现收益。餐厅版把已生效的组合单独列在选将和排班页。阿禾、潮爪同在前厅时，潮爪离开急送区后额外保留一秒加速。炉生、焰铃同在后厨时，还须实际靠近备锅，焰铃的锅才提前进入可点火状态。焰铃属于后续收藏候选。[云顶赛季机制说明](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/cyber-city-overview/)
