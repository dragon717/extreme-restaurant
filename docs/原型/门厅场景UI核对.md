# 门厅场景 UI 核对

首页从峡谷直接开始。餐厅招牌、屋顶点击和继续放大都通往同一座门廊，营业簿采用上沿装订的双层纸页。鼠标或手指可以提起空白页角，松开后纸页回弹。文字的命中位置跟随纸面的实际三角网格，同时支持键盘与手柄焦点。旧封面、屏幕左侧菜单和渐变遮罩已从标题场景移除。

| 原入口或功能 | 当前操作 |
| --- | --- |
| 选择章节、查看解锁条件 | 打开门前营业簿的「章节」页。锁定章节可查看解锁条件。 |
| 开始、继续、查看已有结算 | 新开游戏进入「选择本局英雄」。锁定后所选员工与补位小兵单列进店，右下角可加速或跳过。继续按钮读取所选档位，终局存档打开结算。 |
| 选择和保存进度 | 营业簿的左右箭头切换档位。每次新局单独存储。夜间准备时可在设置保存，打烊后自动记录。 |
| 阵容分组 | 峡谷的货运驿站，或营业簿「设置」中的「阵容分组」。英雄页面也可套用、编辑分组。 |
| 开门、关门、返回全景 | 点击实际门扇，或使用营业簿「设置」中的门扇动作。「返回峡谷」恢复全景。 |
| 中文、英文、退出游戏 | 营业簿 → 设置。 |
| 采购、装饰、奖杯 | 三处建筑各有场景招牌。开局前可查看用途，经营中按章节地块与营业阶段进入对应商店。 |
| 当日排班、河埠记录 | 经营中的货运驿站打开排班或设置。河埠打开日报历史，有待预告的客流时可查看预告。 |

## 镜头和室内物件

门厅与经营共用同一个 Godot 3D 世界、相机、门轴、灯具和人物实例。员工脚点使用地面或桥面世界坐标，灯具跟随实体灯架。街道、天气和环境音沿用同一时钟。经营中的转场继续推进订单。人物标签、地图操作提示按镜头用途收起；英雄选择、暂停与日报各自保留专用界面。

原生窗口回归使用鼠标滚轮进入门厅，点击实际门扇和营业簿，验证触摸展开菜单、键盘移焦、分组、语言、独立存档、旧档恢复和进入营业。测试额外比对门前与回到俯视后的人物实例、灯具变换、天气对象和营业时钟。[门厅回归](../../tests/door_entry_test.gd) · [标题场景](../../scenes/title.tscn) · [营业簿](../../scenes/canyon/door_register.tscn)

营业页以章名为主标题，章次和玩法简介使用小字。营业天数与存档编号分行显示。「章节」页说明各章玩法与解锁条件，「设置」页每行一个动作。[纸面和排版回归](../../tests/register_paper_test.gd)
