# 峡谷餐厅 · 地图与界面设计依据

## 地形与建筑

用冷色山体、蓝绿河道和浅色可行走地面把峡谷分成三层。上层是岩脊与货运台，中层是餐厅、前场、主桥与对岸商铺，下层是栈桥和河滩。山脊先决定路的转折，门店随地面高差入位。坡脚留通行宽度，岩壁和树群的暗部留给路径以外的地带。

河水和远山承接大块冷色。橙铜只集中在餐厅灶火、桥灯和几处入口。门店用屋顶轮廓、层高和招牌的落点互相区分。远看要先认得出主桥和餐厅，再看到石材和木纹。

餐厅正门面向市集，厨房补给从侧巷进入。来客、补货和出餐各走可读的路径。夜里只在选中设施或试摆时高亮相关虚线，线沿现有寻路规则反馈绕行与交叉。白天的日常服务沿用自动调度，出餐口积压时玩家可以手动调用河道急送。

以原版地形作为之后版本的对照。老石桥两端、主桥桥头与下游浅滩可作为未来的局部变化点。每个变化先说明改变哪段动线、有没有替代路径，以及如何从事件中读懂变化。元素峡谷参考的是地貌反馈和通过性变化。Riot 的开发说明也记录了团队如何调整草丛开口，以免遮住入口。[Riot 召唤师峡谷实机美术](https://www.leagueoflegends.com/en-gb/news/dev/unleashing-the-elements/) · [元素峡谷原始设计](https://www.leagueoflegends.com/en-gb/news/game-updates/preseason-2020-gameplay-rise-of-the-elements/) · [2024 地图迭代过程](https://www.leagueoflegends.com/en-us/news/dev/dev-season-2024-map-changes/)

## 顶栏与开店前

顶栏共用一整条背板，中央凸起放当前阶段和营业时钟，左槽把金币、声望和闪星并排，右槽放速度、暂停和更多。地图、历史日报、操作设置进入「更多」。房租在临近缴纳时展开，事件在触发时弹出，二者都有可回看的入口。

开店前让布局、菜单和当天应急能力围绕同一个「开店」动作。营业后把界面重心交还场地，只有当前可用的手动技能才占操作位。结算先读结果，再展开原因和历史对照。Riot 的选人流程明确区分预选、禁用、选择、锁定与备战配置，官方也记录了简化辅助动画、强化关键点击反馈的取舍。剧情型参考选了《Spirit Bonds》和《Demacia Rising》，分别用于看角色叙事怎样分阶段展开，以及经营地图怎样随章节增加地点。[选人流程与节奏](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-24-notes/) · [选人界面反馈](https://www.leagueoflegends.com/en-au/news/dev/client-cleanup-champ-select-end-of-game/) · [Riot 客户端动效](https://www.riotgames.com/en/news/animation-league-legends-client) · [Spirit Bonds](https://www.leagueoflegends.com/en-us/news/dev/creating-spirit-bonds/) · [Demacia Rising](https://www.leagueoflegends.com/en-gb/news/game-updates/league-of-legends-patch-26-7-notes/)

## 角色头顶信息

原型统一采用「身份行 → 当前状态 → 量化进度」的结构。名字稳定，职业放在身份行旁，状态借用同一条凹槽。LoL 在血量和资源条上方支持冠军名或玩家名，控制等状态可在这个区域获得优先显示。餐厅借鉴的是身份、状态和量值的层级。烹饪进度与等餐耐心使用同一构件，进度语义随状态清楚标注。[Riot 名字显示设置](https://www.leagueoflegends.com/en-gb/news/game-updates/patch-2025-s1-3-notes/) · [头顶状态图例](https://wiki.leagueoflegends.com/en-us/Health_bar)

- **通用状态**　移动、待命、受阻、完成。移动和待命在远景收回名称，只保留必要的职业标记。受阻用同一种警示图形和词汇，完成只在进度走完时给一次短光。
- **厨师**　上排显示名字和厨师职业。备餐显示当前一锅的进度。三锅旺火激活时，在相同位置显示一次独立的金色技能提示，状态取自实际烹饪任务。
- **服务员**　上排显示名字和岗位。状态随接单、交单、取餐、送餐切换。玩家启动河道急送后，正在获得加速的信使显示短时状态。技能的可用与冷却总览留在玩家操作区。
- **客人**　平常优先读状态。被选中、特殊到访或耐心临界时展开名字与身份。等餐显示剩余耐心，用餐显示用餐进度。相邻角色只让选中或需要关注的标记展开，遮挡中的常态名称收起。

动效分在三个层面。面板转场给出进入场景的深度，关键状态变化给一次轮廓高光，场景与庆祝粒子留在背景或短时事件中。固定视角下应能在平时看清人和道路，靠近才读到技能说明。

地图中的民国元素按架空飞艇货运码头处理。UI 样稿中的角色名字和数值用于说明层级。

## 开局与分期建造

[第一天的小屋](峡谷开局-一间小屋.png)与[成熟期的峡谷餐厅](峡谷底图-美术稿.png)共用河槽、双桥、驿站和门前道路的位置。开局的暖色屋顶只占西岸一小块，其余可扩建处呈现为草坡和岩地。两张图分别作为开局和成长后的美术目标。实机使用可操作的剖开屋顶，便于看清灶位、客桌和通道。

扩建沿已有付费地块顺序进行。成功确认后，从相邻的旧屋边铺出地板，再立起外墙木架、安上檐口，最后出现新增设施。相接处自然连通。读档时直接呈现存档所处的建设阶段。柱、梁、檩与屋顶分层的造型参考传统木构现场装配。1.55 秒的四段施工节奏与镜头构图是本作设计。[联合国教科文组织木构技艺档案](https://ich.unesco.org/en/RL/chinese-traditional-architectural-craftsmanship-for-timber-framed-structures-00223)

章节推进与建筑成长参考 Riot 的《Demacia Rising》，冷暖分层、可走地面与地标的明暗关系参考召唤师峡谷的环境美术。[Demacia Rising 建筑升级](https://www.leagueoflegends.com/en-gb/news/game-updates/league-of-legends-patch-26-7-notes/) · [元素峡谷环境设计](https://www.leagueoflegends.com/en-us/news/dev/unleashing-the-elements/)

后续每项新增美术或岗位能力，设计时记录三件事：具体参考作品与一手出处、借鉴的造型或机制、项目内实际采用的素材及来源。原图只用作对照；打包素材单独记录原创、生成或授权出处。这张小屋图用内置 ImageGen 编辑项目自有的成熟期美术稿，提示重点为同机位、同路网、单屋、一处灶火和自然的预留地。

未建土地使用本作的[草岩地表贴图](../../assets/materials/canyon-meadow.png)，由内置 ImageGen 根据峡谷成熟期美术稿生成。提示重点为俯视、无方向光、苔草与裸露板岩的连续大色块、安静的地表纹理。实机采用 512 像素导入与多级纹理缩小过滤，按批绘制草地和植被。

## 河港实机的屋顶与镜头

开局房屋沿[一间小屋](峡谷开局-一间小屋.png)的主屋脊、烟囱、前山墙与门洞搭建实体结构。扩建后的主厅使用[成熟期美术稿](峡谷底图-美术稿.png)的高脊、前抱厦与临河露台。后厨凸窗、前厅廊台和入口形成少数转折，室内桌椅、灶位、通道和地块仍以完整方格计。两个机位共用地基、外墙、庭院井台和双桥。进入营业视角时从前檐剖开屋顶。手动从峡谷全景拉到最大可以检视整座屋顶，点「看室内」可在原机位掀开屋面。滚轮、触控板捏合和双指纵向滚动都能调整镜头。

原型画面的明暗关系参考召唤师峡谷 PC 版。屋瓦、石材、木板、灰泥与针叶采用本项目生成的材质板，模型通过 UV 读取颜色和切线空间法线。河谷地标和餐厅构件分别保存在两份可编辑的 Blender 场景里。[峡谷美术参考](https://www.leagueoflegends.com/en-us/news/dev/unleashing-the-elements/) · [手绘材质板](../../art_source/canyon/河港手绘材质板.png) · [河港建筑组](../../art_source/canyon/河港建筑组.blend) · [餐厅构件](../../art_source/canyon/餐厅木石构件.blend)

## 门厅与「选择本局英雄」

在峡谷中点餐厅招牌、点屋顶或继续放大，镜头沿同一座房屋降到西侧门廊的视线高度。左右门扇绕各自铰链向店内打开，门洞后方能看见当局的地板、窗和桌位。门厅可选择章节、存档或新开游戏。选定存档或确认阵容后，门扇完全打开，镜头越过门槛并抬回经营俯视角。营业期间从全景返回餐厅也经过这道门。

「选择本局英雄」参考 PC 版英雄联盟的预选与锁定层级。左侧是五个阵容位及可用员工池，右侧跟随预选展示角色原画、称号与餐厅本领。「加入阵容」确定个人位置，「锁定阵容」开始新局。可套用分组并调整潘森的岗位。此处采用本作的五人选将规则。背景为本项目生图，英雄头像与原画采用已有授权范围内的 Riot Data Dragon 素材。[Riot 选将流程说明](https://www.leagueoflegends.com/en-sg/news/game-updates/patch-25-24-notes/) · [英雄能力预览与锁定](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-15-notes/) · [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)


列表的层级参考《光与影：33号远征队》UI 美术设计师公开的 HUD 概念稿，以及英雄联盟客户端的角色预览与确认流程。本作在门厅、阵容、采购和日报中用整块背景承载列表，普通行以留白和文字对齐分隔。焦点与当前选择使用一笔低透明度的暖金色笔触；「锁定阵容」保留最高对比度。分组操作按需展开。[Brieuc Inisan 的《33号远征队》HUD 概念稿](https://brieucinisan.artstation.com/projects/Gvd0VV) · [Riot 客户端选择界面的设计与反馈](https://www.leagueoflegends.com/en-au/news/dev/client-cleanup-champ-select-end-of-game/)


门口的营业簿把 Godot 子视口的墨字印在可变形的纸页上。上沿固定，纸纤维纹理、字和按钮随同一张网格弯曲。鼠标和触摸命中变形后的纸面，键盘和手柄焦点进入当前页。营业、章节、设置分开排版。营业页大字展示章名与进度，章次、玩法简介和档号采用较小字号。

从峡谷经过店门到经营俯视时，三段镜头共用餐厅、门轴、灯、员工立绘及环境时钟。门前的暖光固定在门廊灯具上，水流落在出餐口的地面。店内家具与本局布局一致。白天镜头移动期间继续结算订单和员工行动。

门廊近景使用入口专用的手绘材质图集。扇窗、拱石和铜环的轮廓由实际几何承接，木纹、气泡、细锤痕与表面粗糙度由贴图呈现。局部打光把灯笼暖光与门廊开口的冷色反光接在同一座建筑上。[手游参考、材质母版和提示词](../../art_source/canyon/门廊材质/材质与生成依据.md)
